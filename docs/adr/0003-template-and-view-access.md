# Project Template bundles Status Profile plus field defs, views gated by membership and role

A Project Template is a Status Profile plus its custom field definitions. Applying a template copies both into the Project, so Procurement and Monthly Rentals have different stages and fields while Tasks in one Project share one schema. Visibility is two-axis: project_members decides which Projects you see, global role plus per-Project role decides which views (Board/List/Calendar/Table/Timeline/Dashboard/Workload/Settings) you may open, enforced backend and frontend.
